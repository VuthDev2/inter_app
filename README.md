# QuickVoice

Real-time voice interpretation across mobile and web.

## Project structure

```text
apps/
  mobile/      Expo, React Native, iOS, and Android
  web/         React website
packages/
  shared/      Shared types and utilities
docs/          Setup and architecture notes
supabase/      Database and backend configuration
extension/     Google Chrome extension
```

See [local setup](docs/setup.md) to get started.

For instructions on loading the Chrome extension, see the [extension README](extension/README.md).
